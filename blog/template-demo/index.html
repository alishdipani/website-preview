Text and structure#

Body text is set in a single narrow column of about 65–70 characters per line. Each ## heading starts a numbered section, and the marker above it (“01 / 06”) is added automatically. Hovering over a heading shows its anchor link, so any section can be linked to directly.

A third-level heading#

Third-level headings divide a section without starting a new one; they get anchor links too, but no section marker. Inline code, bold, italic and links look like this.

A pull quote lifts one sentence out of the text and sets it apart.

The paragraph after a pull quote continues the argument. Pull quotes repeat text from the surrounding section rather than adding new content.

02 / 06

Notes and citations#

Footnotes use the normal Markdown syntax.1 On a computer, hovering over the number shows the note; on a phone, tapping it jumps to the list of notes at the end of the post.2

Citations come from the post’s own .bib file, written as [@key] in the text. A single source looks like this [1], and several at once like this [2, 3]. Each citation gets a number in order of first use, a hover preview, and an entry in the reference list at the bottom. Citing a source again reuses its number [1].

Sidenotes sit in the right margin on wide screens.A sidenote is a short aside that doesn’t need its own footnote. On phones it appears indented, right below the line it belongs to. They suit short asides that the reader can take or leave without losing the thread.

Math and code#

Math is written in LaTeX between double dollar signs, inline like eiπ+1=0e^{i\pi} + 1 = 0eiπ+1=0 or as a display block:

H(X)=−∑xp(x)log⁡2p(x)H(X) = -\sum_{x} p(x) \log_2 p(x)H(X)=−x∑​p(x)log2​p(x)

Code blocks are highlighted, in light and dark colors that follow the page:

def entropy(p):
    """Shannon entropy, in bits, of a discrete distribution p."""
    return -sum(q * math.log2(q) for q in p if q > 0)
